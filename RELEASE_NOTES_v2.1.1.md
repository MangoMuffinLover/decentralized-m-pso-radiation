# v2.1.1 - IECON 2026 reproducibility release

This release supersedes the repository presentation in v1.1.1 by removing
distributed manuscript files and retaining the code, independent figures,
aggregate evidence, tests, and reproducibility documentation.

## Included

- Modular decentralized M-PSO simulator.
- Static-leader, re-election, canonical-PSO, and hot-standby comparators.
- Archived 500-trial Monte Carlo summaries.
- Communication-fragility and hardware-hardening sweeps.
- Independent vector figures and GitHub preview images.
- SHA-256 condition-identity seed policy.
- 62 deterministic model and regression tests.
- Faculty/reviewer guide, model scope, results guide, and paper-to-code map.

## Scope

This is a reduced-order computational study, not hardware-in-the-loop or
operating-reactor validation. Conclusions are restricted to the documented
model, parameter grids, seed policy, and evaluated comparator architectures.
