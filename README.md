\# Decentralized M-PSO in High-Radiation Swarm Environments



This repository contains the simulation framework, experimental code, and data for the paper:

\*\*"Decentralized M-PSO in High-Radiation Swarm Environments"\*\*



\## Repository Structure

\- `pso\_nuclear\_sim.py`: Core Monte Carlo simulation engine and algorithm implementations.

\- `data/`: Generated dataset across 4,500 Monte Carlo trial runs.

\- `plots/`: Output vector plots for convergence rates and swarm trajectories.



\## How to Run

To reproduce the experimental results:

```bash

python pso\_nuclear\_sim.py
